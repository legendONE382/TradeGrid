# Product Requirements — Rural Trade Network App

## Problem
Rural trading is fragmented across phone calls, visits, and notebooks, causing missed sales, debt confusion, and delivery friction.

## Goal
Provide an offline-first app that digitizes local trading workflows with low data usage and simple UI.

## V1 Features
1. Seller onboarding + verification request
2. Listing creation/editing offline, sync when online
3. Nearby discovery by town/region radius
4. Lightweight order request flow
5. Debt book with partial payment support
6. Admin moderation for listings/users

## Non-functional Requirements
- Android 8+ compatibility
- Works under intermittent connectivity
- Text-first loading; compressed images
- Basic localization-ready strings

## Out of Scope (V1)
- Full wallet/payments integration
- Advanced route optimization
- Rich media chat
